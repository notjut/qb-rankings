  1. 1One score per game

    50 is an average game. Every 10 points is one big step better or worse than average. 70 is excellent. 80 is historic.

  2. 2Eight things count

    Turnovers, passing yards and QBR matter most. Then touchdown passes, the defense he faced, completion rate, rushing and sacks taken.

  3. 3Judged against its own season

    Each game is compared with every other game that same year, so 300 yards in 2003 is worth more than 300 yards today.

  4. 4Full games only

    The quarterback must play all four quarters. If he left hurt, was benched or came in as a backup, the game does not count.

  5. 5Tap any game

    Every game opens to show exactly what pushed it up the list and what held it back.
